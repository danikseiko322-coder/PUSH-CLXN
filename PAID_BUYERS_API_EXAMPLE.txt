РЕАЛЬНЫЕ ПОКУПАТЕЛИ

Сейчас блок покупателей намеренно НЕ содержит выдуманных заказов.

Чтобы показывать реальных покупателей:
1. Backend принимает подтверждение успешной оплаты от твоего платёжного провайдера.
2. Только после успешной проверки создаётся запись:
   {
     "nickname": "alex***",
     "product": "7 дней",
     "paid_at": "2026-09-21T12:00:00Z"
   }
3. Frontend получает только подтверждённые записи через API.
4. Ник лучше маскировать, чтобы не публиковать личные данные без необходимости.

Нельзя считать клик по кнопке или переход на оплату подтверждённой покупкой.
