PUSH CLXN — CARD CHECKOUT EDITION

Запуск:
1) Распакуй ZIP в отдельную папку.
2) Запусти START.bat.
3) Открой http://localhost:3000

Оплата:
- /payment.html — отдельная красивая страница оплаты.
- Цена фиксируется сервером, начиная с 120 ₽ (валюта задаётся в .env (сейчас RUB)).
- Оплата проходит через Stripe Checkout.
- После оплаты сервер проверяет Stripe и помечает заказ paid.
- Данные банковских карт не сохраняются PUSH CLXN.

Для реальных денег:
1) В Stripe активируй аккаунт продавца и подключи банковский счёт для выплат.
2) Создай новый Secret Key и вставь его только в .env.
3) Укажи PUBLIC_BASE_URL для опубликованного сайта.
4) Для production настрой webhook /api/stripe-webhook и STRIPE_WEBHOOK_SECRET.
5) SHOP_CURRENCY=rub означает цены в фунтах. При смене валюты проверь поддержку этой валюты в Stripe и синхронность цен.

ВАЖНО: секретный ключ из исходного ZIP удалён из исправленной версии. Если он где-либо публиковался, его следует отозвать/заменить в Stripe. Stripe должен быть активирован, а банковский счёт подключён в Dashboard.

Не вставляй номер банковской карты, CVV или PIN в код.

Подробная инструкция: SETUP_PAYMENT.txt


ОБНОВЛЕНИЕ ОПЛАТЫ:
- Адрес и телефон больше не запрашиваются принудительно в Stripe Checkout.
- Apple Pay показывается Stripe автоматически на совместимых устройствах/браузерах, если он доступен для аккаунта и покупателя.
- Заказ считается оплаченным только после подтверждения Stripe payment_status=paid.
- Checkout-сессия истекает через 30 минут, если её не оплатили.
- RUB (₽) используется на сайте и в Checkout.
